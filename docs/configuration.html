Configuration

There is no settings file. What can be configured is the key, one prop, and a few constants at the top of main.js.

Key binding

The repository's keys.json binds Ctrl+Shift+A in global and terminal to the command mod.open:attention-picker. Change the left side to any key Herdr accepts. Herdr applies keys.json live. See Install.

Props

Props are given by whatever opens the overlay. Opening it with its key passes none, so the search box is on.

PropValuesEffect
searchfalse or anything else, including absentAbsent or any value except false shows the search box. false gives the keys-only variant with 1-9 jump badges.

To open it from your own mod:

openOverlay({ mod: "attention-picker", kind: "dialog", width: 640, props: { search: false } });

The overlay description in mod.json is a dialog 640 px wide. The mod also receives overlay (its overlay id) from Herdr and uses it to close itself.

Shared keys

Herdr keeps a small key-value store that every mod can read. This mod uses three keys and keeps its names stable so other layouts can rely on them.

KeyMod accessMeaning
attention.sortreads and writesrecent, oldest or space. Any other value is read as recent.
agents.sincereads onlyAn object from agent address to the epoch milliseconds when it entered its status. Optional. When present it wins over the mod's own tracking. The mod never writes it.
space.colorsreads onlyAn object from space id to a colour: an ansi1 to ansi6 name from the theme, or a #rrggbb value. Optional; spaces without an entry use teal (ansi6).

The command it runs

Choosing an agent runs Herdr's agent.focus command with that agent's terminal address, then closes the dialog.

Constants

These are named at the top of mods/attention-picker/main.js. Edit a copy, not the live folder (see How it works).

NameValueMeaning
HOMEmods/attention-pickerThe mod's folder, used to load its icons. Change it with the folder name.
POLL_MS3000 (milliseconds)How often the previews are refreshed while the dialog is open.
READ_LINES60Lines of history above the visible screen asked of hc read (--lines).
READ_CONCURRENCY4Most terminals read at the same time.
