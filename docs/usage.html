Usage

Open it

Press Ctrl+Shift+A (the key in this repository's keys.json). Pressing it again should close it, because Herdr's mod.open toggles; Esc always closes it. The search box has the focus as soon as it opens.

What it lists

Only agents: terminals whose program reports a status to Herdr (the same list Herdr's own agent panels use). A plain shell does not appear, even in a space full of open terminals; with no agent at all the dialog says "No agents running".

The statuses it uses are blocked (needs you), done (finished while you were not looking), working and idle. Herdr turns a finished agent into an idle one once you look at it, here or on another Herdr client, so a finished agent leaves the top list as soon as you have looked at it and then sits under the rule.

Reading the dialog

  1. Title. "N agents need you" when some are blocked, otherwise "N finished" when some are done, otherwise "Nothing needs you right now". With no agents at all it says "No agents running" and, under it, "Start one and it will show here". The title counts all your agents, whatever you type in the search box.
  2. Needs you, then finished. A plain list, blocked agents first, then done ones, each group in the order Herdr last saw the agents change. Each has two lines. The first has a status dot, the agent's name, the status word (needs you or finished), how long it has been in that status, and its space and tab. The second line is a preview of what the agent asked or said.
  3. A rule. Shown only when there are agents on both sides of it.
  4. Everyone else (working, idle, unknown), grouped under their space. The space's initial sits on its color, drawn in white or near-black, whichever reads better; the color comes from Herdr's shared space.colors and is teal when none is set. A working agent shows a spinner.
  5. "earlier". Agents that are not working, not focused, and have been in their status for over 24 hours fold into one line: "earlier: N agents idle for over a day". The fold needs a known start time; an agent with none stays in the main list. Select the line and press Enter (or click it) to open or close the fold.

The name of an agent is its title when that looks like a name (not a path, not an address with @, not just the program name); otherwise a named tab; otherwise the program.

A space named ~ (what Herdr calls the home folder) has its tile drawn in the dim text color instead of a space color. It is only cosmetic.

Keys

KeyDoes
Up, DownMove the selection; it wraps at both ends. The selection stays on the same agent when the list reorders.
EnterGo to the selected agent: Herdr focuses it and the dialog closes. On the "earlier" line it opens or closes the fold instead.
Tab, Shift+TabNext or previous sort for the lower list (not yet observed with the search box focused, see Verification status).
TypingFilters the list (search is on by default).
EscClose.
Click a rowSame as Enter on it.
Mouse wheelScrolls the list (it is at most 320 px tall); the selection follows.

Without the search box (the keys-only variant, see Configuration) the digits 1 to 9 jump straight to the numbered agent, and the number is drawn at the left of each row. Digits are not shortcuts while the search box is on, because you may be typing them.

Search

Type to filter. The text is split into words and every word must match, in any order, somewhere in the agent's name, program, space name, tab name or title, or in its status words (needs you, finished, working, idle, and the raw status). Case does not matter. A non-empty search also opens the "earlier" fold so matches in it are visible. When nothing matches the dialog says "No match".

Sorts

The sort button at the top right shows the current sort and, in its tooltip, the next one. It only orders the lower list; the needs-you and finished rows keep the order Herdr last saw them change.

SortOrder
RecentLatest status change first. This is the default. Agents with no known start come last.
OldestLongest in its status first. Agents with no known start come last, as under Recent.
Space orderAs the space tree lists them.

Spaces follow their first agent in the chosen order. The choice is kept in Herdr's shared value attention.sort, so it survives a restart and other mods can read it.

Waiting times

The time next to a status is how long the agent has been in that status, and it refreshes every 30 seconds while the dialog is open (that redraw has not been watched in the live app yet). Where the start comes from, best first:

  1. Herdr's shared agents.since, if another mod publishes it (the portrait layout does). It is ignored for a blocked or working agent that is alone in its tab when the tab shows a change more than 10 seconds newer, because a value left behind by a layout you stopped using can be stale.
  2. The agent's tab: its working_since for a working agent, its changed_at (when something in the tab last changed state) for any other. It is exact for a tab with one agent and approximate for a tab with several.
  3. A first-seen time the mod records itself: the first moment the dialog saw this agent in its current status.

Limit. The dialog only exists while it is open, so it cannot see changes that happen while it is closed. When the first two sources have nothing, an agent that went idle yesterday looks new until the next time you open the dialog, and its time counts from then. Times are estimates.

Previews

For blocked and finished agents the second line shows what the agent asked or said, read from the end of its terminal's text (the screen plus up to 60 lines of history above it; only the last 40 non-empty lines are looked at). For a blocked agent it is the last line that ends in a question mark, or a yes/no hint such as (y/n) or [y/N]; for a finished agent it is the agent's last message, skipping tool-call lines. Until the first read returns the line shows an ellipsis. A screen that has not changed is read again about every 30 seconds instead of every 3; when the agent's status or Herdr's sequence number for it changes, it is read at once.

This is best effort. The recognized shapes are the ones in the test fixtures, drawn by Claude Code style screens: a question box, a numbered choice, a yes/no hint, and "•" message lines that start in the first column (an indented bullet inside a message is not taken as the message). A question that appears without Herdr's sequence number moving can take up to about 30 seconds to show. Other agents may show a blank second line; the row still works.
