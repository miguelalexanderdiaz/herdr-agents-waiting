Install

The mod is one folder. You copy it, bind a key, and check it.

One command

macOS and Linux:

curl -fsSL https://raw.githubusercontent.com/miguelalexanderdiaz/herdr-agents-waiting/main/install/install.sh | sh

Windows (PowerShell):

irm https://raw.githubusercontent.com/miguelalexanderdiaz/herdr-agents-waiting/main/install/install.ps1 | iex

It says what the mod reaches (no network; hc read on waiting agents' screens while the list is open) and asks before writing anything. Then it copies mods/attention-picker into your Herdr home, adds ctrl-shift-a to keys.json (asking before it replaces a key you use) and runs herdr-app check. Anything it replaces is backed up first under community/herdr-agents-waiting/ in the Herdr home, and running it again updates in place. sh -s -- --yes answers every question with yes (Windows: $env:HERDR_YES = 1 first); --home <folder> or HERDR_APP_HOME picks another Herdr home; from a clone, run install/install.sh or .\install\install.ps1. Merging keys.json uses Node, or on macOS the system's own JavaScript; without either the script prints the keys to add by hand. To remove it: the same line with sh -s -- --uninstall (Windows: $env:HERDR_UNINSTALL = 1 first).

Install with a Herdr agent

Herdr's own instructions tell an agent how to add a shared mod. Paste this into any agent that works in your Herdr home:

Add the Herdr mod from https://github.com/miguelalexanderdiaz/herdr-agents-waiting
(the folder mods/attention-picker). Read RECIPE.md and AGENTS.md in that repo first and
tell me what the mod reaches before you copy anything. Merge its keys.json into mine and
ask me before replacing any key I already use. Then run herdr-app check on the mod folder.

Once the repository is public and listed, the address herdr.dev/mods/miguelalexanderdiaz/herdr-agents-waiting works the same way.

Install by hand

  1. Get the files: git clone https://github.com/miguelalexanderdiaz/herdr-agents-waiting.git or download the repository as a zip.
  2. Copy the mods/attention-picker folder, whole, into the mods folder of your Herdr app home. Herdr's documentation puts that home at ~/.config/herdr-app; if yours is elsewhere, use that (Herdr reads the HERDR_APP_HOME variable for it, see herdr-app --help). Copy the folder as it is: main.js imports logic.js and ask.js, and the icons are loaded from mods/attention-picker/. If you already have a mod with that name, see Name clash.
  3. Open your keys.json in the same home and add the key from this repository's keys.json to the global and terminal sections. If you already use that key, pick another one; do not overwrite yours. 
    {
  "global":   { "ctrl-shift-a": "mod.open:attention-picker" },
  "terminal": { "ctrl-shift-a": "mod.open:attention-picker" }
}
  4. Check the mod: herdr-app check ~/.config/herdr-app/mods/attention-picker. Herdr loads mods and keys live, so there is no restart. Then, from a clone of this repository, run node scripts/verify-install.mjs ~/.config/herdr-app/mods/attention-picker --home ~/.config/herdr-app (Node 22 or newer; set HERDR_APP_HOME instead of --home if you prefer). It is read-only and checks the folder name against HOME, that both icons exist, that mod.json is valid and that your keys.json has a key for mod.open:attention-picker. It has not been run on Linux or Windows.
  5. Press Ctrl+Shift+A.

The check is not a full test. herdr-app check proves the code loads and renders once. It does not run the timers or the screen reads that happen after the dialog has been open for a while, and it passes a broken mod.json or a mod whose folder was renamed without changing HOME; verify-install.mjs covers those two. Open the dialog in the app too.

Other ways to open it

  • The command palette (app.palette) can run mod.open, which needs the argument name (attention-picker). How the palette asks for that argument is not documented by Herdr and has not been tried; see Verification status.
  • From a terminal: herdr-app do mod.open '{"name":"attention-picker"}'. Herdr's command list says mod.open toggles, so running it again closes the dialog. On Windows the quoting of the JSON differs by shell; see Troubleshooting.
  • From another mod: openOverlay({ mod: "attention-picker", kind: "dialog", width: 640 }). See Configuration.

Use a different key

Any key Herdr accepts works. Put "<key>": "mod.open:attention-picker" in the global section (so it works anywhere) and in terminal (so it works while a terminal has focus; a focused terminal uses that more specific section). Pressing the key again should close the dialog, because mod.open toggles; Esc always does. If Ctrl+Shift+A is taken by a program you run in your terminals, bind another key. Avoid cmd (not on Linux or Windows) and ctrl-alt (AltGr on some Windows keyboards).

Name clash

If a mod called attention-picker already exists, do not overwrite it. Copy this one under another name, for example agents-waiting, and change three places: the folder name, the HOME constant at the top of main.js (it is the folder path used to load the two icons), and the name in your keys.json line (mod.open:agents-waiting). Herdr's mod.clone command, run on an installed mod, rewrites that mod's own mods/<name>/ asset paths for the new name; check the HOME constant afterwards.

Update

Replace the folder with the new one (keep your keys.json line) and run the check again. Herdr reloads a mod when its files change. Do this from a copy outside the Herdr home, so the live window never shows a half-copied folder.

Uninstall

  1. Delete the mods/attention-picker folder from your Herdr home.
  2. Remove the mod.open:attention-picker lines from your keys.json.
  3. Optional: the mod leaves behind one value in Herdr's shared state, attention.sort (your chosen sort), and its first-seen times in its local storage (key attention.seen, kept per mod copy). Nothing reads them once the mod is gone.

Verification status

What has and has not been seen. The original mod ran in the author's Herdr on macOS (0.1.12). Everything added since then passed herdr-app check and the unit tests, which cover the pure code and run the view under Node against stand-ins for Herdr's modules. None of it has been watched in a live window, and nothing has been run on Linux or Windows.
