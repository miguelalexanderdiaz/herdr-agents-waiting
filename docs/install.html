Install

The mod is one folder. You copy it, bind a key, and check it.

Requirements

NeedDetail
Herdr appChecked against 0.1.12. The mod uses only Herdr's documented mod API, so newer versions should work; an older one may not.
Node, npm, a networkNot needed to run it. Node 22 or newer is needed only to run the tests in this repository.
Other modsNone. It works in a bare Herdr install.

Install with a Herdr agent

Herdr's own instructions tell an agent how to add a shared mod. Paste this into any agent that works in your Herdr home:

Add the Herdr mod from https://github.com/miguelalexanderdiaz/herdr-agents-waiting
(the folder mods/attention-picker). Read RECIPE.md and AGENTS.md in that repo first and
tell me what the mod reaches before you copy anything. Merge its keys.json into mine and
ask me before replacing any key I already use. Then run herdr-app check on the mod folder.

Once the repository is public and listed, the address herdr.dev/mods/miguelalexanderdiaz/herdr-agents-waiting works the same way.

Install by hand

  1. Get the files: git clone https://github.com/miguelalexanderdiaz/herdr-agents-waiting.git or download the repository as a zip.
  2. Copy the mods/attention-picker folder into the mods folder of your Herdr app home. Herdr's documentation puts that home at ~/.config/herdr-app. Copy the folder as it is, because the icons are loaded from mods/attention-picker/. If you already have a mod with that name, see Name clash.
  3. Open your keys.json in the same home and add the key from this repository's keys.json to the global and terminal sections. If you already use that key, pick another one; do not overwrite yours. 
    {
  "global":   { "ctrl-shift-a": "mod.open:attention-picker" },
  "terminal": { "ctrl-shift-a": "mod.open:attention-picker" }
}
  4. Check the mod: herdr-app check ~/.config/herdr-app/mods/attention-picker. Herdr loads mods and keys live, so there is no restart.
  5. Press Ctrl+Shift+A.

The check is not a full test. herdr-app check renders the mod once. It does not run the timers or the screen reads that happen after the dialog has been open for a while, so also open it in the app.

Other ways to open it

  • The command palette (app.palette) lists the mod.open command.
  • From a terminal: herdr-app do mod.open '{"name":"attention-picker"}'. Running it again closes the dialog.
  • From another mod: openOverlay({ mod: "attention-picker", kind: "dialog", width: 640 }). See Configuration.

Use a different key

Any key Herdr accepts works. Put "<key>": "mod.open:attention-picker" in the global section (so it works anywhere) and in terminal (so it works while a terminal has focus). The same key toggles: it opens the dialog and closes it. If Ctrl+Shift+A is taken by a program you run in your terminals, bind another key.

Name clash

If a mod called attention-picker already exists, do not overwrite it. Copy this one under another name, for example agents-waiting, and change three places: the folder name, the HOME constant at the top of main.js (it is the folder path used to load the two icons), and the name in your keys.json line (mod.open:agents-waiting). Herdr's mod.clone command, run on an installed mod, rewrites that mod's own mods/<name>/ asset paths for the new name; check the HOME constant afterwards.

Update

Replace the folder with the new one (keep your keys.json line) and run the check again. Herdr reloads a mod when its files change. Do this from a copy outside the Herdr home, so the live window never shows a half-copied folder.

Uninstall

  1. Delete the mods/attention-picker folder from your Herdr home.
  2. Remove the mod.open:attention-picker lines from your keys.json.
  3. Optional: the mod leaves behind one value in Herdr's shared state, attention.sort (your chosen sort), and its first-seen times in its local storage (key attention.seen, kept per mod copy). Nothing reads them once the mod is gone.
