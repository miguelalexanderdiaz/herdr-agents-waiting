Install

macOS and Linux

curl -fsSL https://raw.githubusercontent.com/miguelalexanderdiaz/herdr-agents-waiting/main/install/install.sh | sh

Windows (PowerShell)

irm https://raw.githubusercontent.com/miguelalexanderdiaz/herdr-agents-waiting/main/install/install.ps1 | iex

It shows what the mod reaches and asks before writing anything, backs up anything it replaces, and checks the mod. Running it again updates. Then Ctrl+Shift+A opens the list.

Remove it: the same command with the uninstall flag.

curl -fsSL https://raw.githubusercontent.com/miguelalexanderdiaz/herdr-agents-waiting/main/install/install.sh | sh -s -- --uninstall
$env:HERDR_UNINSTALL = 1; irm https://raw.githubusercontent.com/miguelalexanderdiaz/herdr-agents-waiting/main/install/install.ps1 | iex

Needs Herdr (tested on 0.1.12 only). No other mod, no network.

With an agent

Paste this into an agent that works in your Herdr home:

Add the Herdr mod from
https://github.com/miguelalexanderdiaz/herdr-agents-waiting
(the folder mods/attention-picker). Read RECIPE.md and AGENTS.md
in that repo first and tell me what the mod reaches before you
copy anything. Merge its keys.json into mine and ask me before
replacing any key I already use. Then run herdr-app check on the
mod folder.

The steps the agent follows are in AGENTS.md.

By hand
  1. Clone the repository: git clone https://github.com/miguelalexanderdiaz/herdr-agents-waiting.git
  2. Copy the whole mods/attention-picker folder into the mods folder of your Herdr home (~/.config/herdr-app, or HERDR_APP_HOME).
  3. Add the key to both sections of your keys.json. If you already use it, pick another key. 
    {
  "global":   { "ctrl-shift-a": "mod.open:attention-picker" },
  "terminal": { "ctrl-shift-a": "mod.open:attention-picker" }
}
  4. Run herdr-app check ~/.config/herdr-app/mods/attention-picker. Herdr loads mods and keys live, so there is no restart.
Options, name clashes and checks

Options

  • No questions: sh -s -- --yes (Windows: $env:HERDR_YES = 1 first).
  • Another Herdr home: --home <folder> or HERDR_APP_HOME.
  • From a clone: install/install.sh or .\install\install.ps1.
  • Backups go to community/herdr-agents-waiting/ in the Herdr home.
  • Merging keys.json uses Node, or on macOS the system's own JavaScript; without either the script prints the keys to add by hand.
  • Uninstalling removes only what it installed, and only the keys you have not changed since.

Name clash

If you already have a mod called attention-picker, keep it. Install this one under another name and change three places: the folder, the HOME constant at the top of main.js, and the name in your keys.json line (mod.open:<new name>).

Checks

herdr-app check proves the mod loads and renders once. It does not run the timers or screen reads, and it passes a broken mod.json or a renamed folder with the old HOME. For those, run node scripts/verify-install.mjs <mod folder> --home <Herdr home> from a clone (read-only, Node 22 or newer). What nobody has observed yet is listed under Verification status.

Update or remove by hand

Update: replace the folder with the new one, from a copy outside the Herdr home, and run the check again. Remove: delete mods/attention-picker and the mod.open:attention-picker lines in keys.json. The sort choice (attention.sort) and the first-seen times (attention.seen) stay behind; nothing reads them once the mod is gone.
